## Introduction

In this room, I learned the basics of SQL and how databases store and manage information. I also learned how to write simple SQL queries to create, read, update, and delete data.

## Databases 101

A database is used to store information in an organized way.

Data is stored inside **tables**, where each table contains:

- Rows (records)
- Columns (fields)

For example, a users table may contain:

- ID
- Username
- Email
- Password

## What is SQL?

SQL (Structured Query Language) is the language used to communicate with databases.

It allows us to:

- Retrieve data
- Insert new data
- Update existing data
- Delete data
- Create databases and tables

## Database and Table Statements

I learned how databases and tables are created using SQL statements.

Common statements include:

- `CREATE DATABASE`
- `CREATE TABLE`
- `DROP DATABASE`
- `DROP TABLE`
- `ALTER TABLE`

These commands are used to manage the database structure.

## CRUD Operations

CRUD stands for:

- **Create** → `INSERT`
- **Read** → `SELECT`
- **Update** → `UPDATE`
- **Delete** → `DELETE`

These are the four basic operations used when working with databases.

## SQL Clauses

Clauses help filter and organize query results.

Some common clauses are:

- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `LIMIT`

These make SQL queries more specific and useful.

## SQL Operators

Operators are used to compare values or combine conditions.

Examples include:

- `=`
- `!=`
- `>`
- `<`
- `>=`
- `<=`
- `AND`
- `OR`
- `NOT`
- `LIKE`
- `IN`

These operators help search for specific data.

## SQL Functions

Functions perform calculations or modify data.

Some common functions are:

- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`

These are useful when working with large amounts of data.

## Key Takeaways

- SQL is used to communicate with databases.
- Data is stored in tables made of rows and columns.
- CRUD operations are the basic database actions.
- Clauses help filter and sort results.
- Operators compare values and create conditions.
- SQL functions perform calculations on data.
