# Burp Suite: The Basics

## Introduction

In this room, I learned the basics of Burp Suite, one of the most popular tools used for web application security testing.

Burp Suite acts as an intercepting proxy between my browser and a web server. This allows me to inspect, intercept, modify, and replay HTTP requests and responses before they reach the server.

During this room, I learned how to:
- Understand the purpose of Burp Suite
- Navigate the Burp Suite interface
- Configure Burp using FoxyProxy
- Use the Target Site Map to discover hidden endpoints
---

## Burp Suite Editions

Burp Suite is available in two editions:

### Community Edition

The Community Edition is free and mainly focuses on manual web application testing. It includes useful tools such as Proxy, Repeater, Decoder, Comparer, and a limited version of Intruder.

### Professional Edition

The Professional Edition is the paid version of Burp Suite. It includes additional features such as an automated vulnerability scanner, website crawler, project saving, and report generation, making it more suitable for professional penetration testers.
